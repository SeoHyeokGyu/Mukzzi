# Mukzzi (뭐먹지) — 기능 및 화면 보고서

> AI 기반 음식 추천 & 캐릭터 성장 앱. 매일의 "뭐 먹지?"를 해결하고, 먹은 음식으로 캐릭터 **먹찌**를 키우는 게이미피케이션 식사 기록 앱.

**캡쳐 환경** — Flutter Web (canvaskit) · 뷰포트 390×844 모바일 · 2x · 계정 `admin`
**캡쳐 일자** — 2026-06-28

---

## 1. 홈 / 메뉴 결정

먹찌 캐릭터, 오늘의 영양 현황, 연속 기록(스트릭), 메뉴 결정 진입을 한 화면에 모은 메인 대시보드.

| 홈 | 퀘스트 |
|----|--------|
| ![홈](01-home.png) | ![퀘스트](02-home-quests.png) |

- **홈**: 먹찌 상태, 오늘의 영양(칼로리/탄·단·지), 연속 기록, 먹찌 밥 주기 / 촬영 진입
- **퀘스트**: 일일·주간 퀘스트로 식사 기록 동기 부여

| 식사 기록 | 먹부림 캘린더 | 식사 숙련도 |
|-----------|---------------|-------------|
| ![식사기록](03-meal-record.png) | ![캘린더](04-meal-calendar.png) | ![숙련도](05-meal-masteries.png) |

- **식사 기록**: 끼니 기록 입력/조회

## 참고 사항

- 캡쳐 계정 `admin` 기준. 캡쳐 시점 오늘 식사 0건 → 홈/캐릭터 일부 수치가 0으로 표시.
- 방명록·도감 등 일부는 데이터 없어 빈 상태(empty state)로 노출.
- 로그인(`/auth`) 화면은 헤드리스 canvaskit 첫 프레임 공백 이슈로 미포함.
- 캡쳐 방법: 백엔드 `/auth/login`으로 JWT 발급 → `localStorage` 주입 → go_router 해시 라우트 deep-link → Playwright 스크린샷.
